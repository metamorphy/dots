b) Assuming won't play ? because that gives opponent choice.

Rules:
If 0 or 4 shorts is parity 0
If 1 or 2 shorts is parity 1
If 3 or 5 shorts, have choice:
  Play in middle for 1
     (only choice if only one 1-box)
     (in 33B, 36, 37, etc., middle is 2-path not connected 
        to another box other than center)
  Play next to middle for 0
     (careful how to define this for 47)

Parity 1 algorithm   Works for 23A,24,25,33A,33B,36,43,37
    * Find box A only connected to 1 other 1-box B
    * countBoxes = 1
    X if (2*countBoxes >= totalBoxes)
        return path A-B
    * countPaths = 2-paths out of A
    * if (2*countPaths >= totalPaths)
         return path A-B
    * If countPaths >= (totalPaths-1)/2 //If 2*countPaths+1 == totalPaths 
        [In 33b do after 1 out of 3.  In 36 do after 2 out of 6]
         find path out of B that doesn't connect to a 1-box
             if one was found, play it
    * countPaths += 2-paths out of B - 1
    * Find path out of B that leads to a 1-box C where C!=A
    * A = B, B = C, ++countBoxes
    * Goto X 

Parity 0 algorithm   Works for 23A,24,25,33A,33B,36,43,37
    * Find path from Parity 1
    * For each 1 on path
        If has another path, return that

Depends how distributed, i.e. 23 might have 3 shorts around 1.
    This is a 0 rather than a choice...

If 0 or 1 shorts, these are same results as for no 1-box,
so 1-box can be ignored.
